# نتيجة اختبار المتصفح — خطأ اسم onboarding

**التاريخ:** 2026-08-17
**المسار:** `http://localhost:3004/onboarding`
**الحالة:** PASS

## السيناريو

فُتحت خطوة «عن يومك» في onboarding، وبقي حقل الاسم فارغًا، ثم أُرسل النموذج عبر زر «التالي» دون إدخال بيانات أو تعديل المدينة. ظهرت الرسالة العربية `اكتب اسمك أولًا.`.

## نتيجة فحص DOM

| العنصر | النتيجة |
|---|---|
| نص الخطأ | `اكتب اسمك أولًا.` |
| `role` | `alert` |
| `aria-live` | `assertive` |
| `aria-atomic` | `true` |
| `aria-describedby` في الحقل | `onboarding-name-error` |
| `aria-invalid` في الحقل | `true` |
| قيمة الحقل | فارغة |

أثبت الفحص أن رسالة الخطأ قابلة للإعلان الفوري، وأن الحقل مرتبط بها دلاليًا، مع بقاء النص العربي ومنطق التحقق كما هو. لم تُنشأ بيانات onboarding اختبارية.
