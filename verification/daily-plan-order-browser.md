# اختبار ترتيب خطة اليوم حسب الوقت والأولوية

- المسار: `/daily-plan` على `http://localhost:3004/daily-plan`.
- تم اختيار التاريخ التجريبي `2026-08-16` عبر حقل التاريخ، وظهرت عناصر الخطة بدل حالة الخطة الفارغة.
- ظهرت رسالة عربية واضحة تشرح أن الترتيب حسب وقت العنصر ثم أولوية المهمة عند تساوي الوقت، وأن النظام لا يغيّر المواعيد تلقائيًا.
- ظهرت عناصر الـTimeline بالترتيب الزمني: 08:30، 10:00، 12:15، 13:00، 15:30، 17:00، ثم عنصر اختبار مضاف بوقت 20:39.
- بقيت روابط السياق وأزرار الإكمال والتأجيل والتخطي والتعديل والنقل إلى يوم آخر ظاهرة وقابلة للاستخدام.
- بقيت مؤشرات التقدم والتركيز الحالي متاحة، ولم تظهر أخطاء runtime أو hydration في الحالة المرئية.
- أُجريت بوابات TypeScript وESLint و`git diff --check` و`next build` بنجاح قبل الاختبار.
