# تحقق اعتماد الحقول المشتركة في المساحات — 2026-08-16

## النطاق

اعتمدت `WeeklyReviewWorkspace` على `Textarea` المشترك لحقول المراجعة، واعتمد `ReligiousWorkspace` على `Input` و`Select` و`Textarea` في اسم قائمة التلاوة، وتدبر الآيات، وإعدادات المدينة وطريقة الحساب.

## الفحص البصري والتفاعلي

فُتحت `http://localhost:3004/religious` بصريًا. ظهرت قائمة التلاوة وTextarea التدبر وحقلا المدينة وطريقة الحساب ضمن RTL مع الحفاظ على النصوص والقيم الحالية. غُيّرت قائمة طريقة الحساب إلى «مخصص» وهي القيمة الحالية، وتأكد بقاء الصفحة والمحتوى دون فقدان أو تغيير بيانات مقصود.

فُتحت `http://localhost:3004/review` بصريًا. ظهرت حقول «ماذا سار جيدًا؟» و«ما الذي عطّلك؟» و«ما هدف الأسبوع القادم؟» بصيغة RTL مع القيم الحالية والأزرار المجاورة. راجعت console بعد التحميل؛ ظهرت رسائل React DevTools وHMR الطبيعية فقط، دون أخطاء runtime أو hydration.

## السلامة

حُفظت كل handlers والـcontrolled/uncontrolled props كما كانت، ولم تُضف بيانات تجريبية أو migrations أو secrets. المكونات الجديدة تغلف عناصر HTML الأصلية وتبقي خصائص الوصول والـaria labels الحالية.
