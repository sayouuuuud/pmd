# تحقق البحث الشامل — Dialog المشترك — 2026-08-16

## النطاق

رُحّلت نافذة `GlobalSearchDialog` إلى `components/ui/dialog.tsx` مع إضافة خيار `hideHeader` للمكونات التي تملك رأسًا داخليًا مخصصًا. احتُفظ بشريط البحث، ونتائج الأقسام، والروابط، وزر الإغلاق، ومسح الاستعلام عند الإغلاق، دون تغيير منطق البحث أو ترتيب النتائج.

## الفحص البصري والتفاعلي

فُتحت الصفحة الرئيسية على `http://localhost:3004/`، ثم فُتح البحث الشامل من زر التنقل العلوي. ظهرت النافذة فوق الصفحة مع RTL والـbackdrop الحاليين، وحقل البحث العربي وزر الإغلاق. أُدخلت كلمة «مهمة»، فظهرت نتائج من قسمي «المهام» و«خطة اليوم» داخل القائمة القابلة للتمرير. أُغلقت النافذة عبر `Escape`، فعادت الصفحة الرئيسية إلى حالتها الأصلية واختفى الاستعلام.

## السلامة

لم يتم النقر على نتيجة أو تنفيذ تنقل أو تعديل بيانات المستخدم. لم تُضف أسرار أو migrations. خيار `hideHeader` لا يزيل اسم النافذة من شجرة الوصول؛ إذ يبقى العنوان متاحًا عبر `sr-only`، بينما يظل زر الإغلاق الخاص بالبحث ظاهرًا.
