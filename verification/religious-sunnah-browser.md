# اختبار حفظ السنن والنوافل

التاريخ: 2026-08-16

## السيناريو

1. فتح صفحة `/religious`.
2. تفعيل بطاقة «صلاة الضحى» من قسم «السنن والنوافل».
3. التحقق من ظهور علامة الإنجاز مباشرة في البطاقة.
4. إعادة تحميل الصفحة.
5. التحقق من بقاء «صلاة الضحى» مفعّلة بعد التحميل.
6. فحص console المتصفح.

## النتيجة

نجح السيناريو ذهابًا وإيابًا. أصبحت حالة «صلاة الضحى» جزءًا من `religious.dhikr.sunnahChecks` بدل state محلي مؤقت، وتستمر بعد إعادة تحميل الواجهة عبر التخزين المحلي. لا توجد أخطاء JavaScript أو أخطاء مزامنة ظاهرة في console؛ الموجود فقط رسائل React DevTools وHMR المعتادة في بيئة التطوير.

## النطاق والحدود

الاختبار أُجري مع fallback المحلي لعدم توفر credentials في بيئة التطوير. مسار الخادم يطبّع المفاتيح الأربع (`duha`, `witr`, `rawatib`, `sadaqah`) ويقبلها ضمن الحمولة الدينية عند توفر قاعدة البيانات، بينما تحافظ البيانات القديمة التي لا تحتوي الحقل على القيم الافتراضية غير المفعّلة.
