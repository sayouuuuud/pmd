# تحقق دفعة Playlists وحفظ موضع التلاوة

## النطاق
- إنشاء Playlist محلية باسم «ورد المساء» مع إضافة السورة الحالية تلقائيًا.
- عرض السور المحفوظة داخل القائمة مع زر إضافة/إزالة السورة الحالية.
- إضافة عقد `quran.lastPosition` لحفظ السورة وموضع الصوت بالثواني والقارئ عند توفره.
- استعادة الموضع عند تحميل metadata لنفس السورة، مع زر استئناف التلاوة.
- دعم localStorage fallback وremote sanitization/hydration دون تخزين نص ديني محليًا.

## الاختبار البصري
- المسار: `http://localhost:3004/religious`
- ظهرت بطاقة المصحف والتلاوة داخل RTL، مع حقل «اسم قائمة جديدة»، زر «إنشاء قائمة»، ورسالة الحالة الفارغة.
- بعد الإدخال والإنشاء ظهرت «ورد المساء» مع «1 سور» و«السورة 1» و«إزالة الحالية».
- لم تظهر أخطاء تشغيل من واجهة القسم أثناء الاختبار.

## الاختبار التفاعلي
- إنشاء Playlist نجح دون إعادة تحميل.
- إعادة فتح `/religious` أعادت عرض «ورد المساء» والسورة المرتبطة بها من localStorage.
- بقيت واجهة الأذكار والبطاقات القائمة دون تغيير وظيفي ظاهر.

## ملاحظات
- لم يتم تشغيل ملف صوتي فعليًا أثناء التحقق لأن القارئ يحتاج اختيارًا وتحميل مصدر خارجي؛ منطق `audio` و`onPause` و`onEnded` موصول لحفظ الموضع.
- TypeScript نجح قبل الاختبار البصري.
- لا توجد secrets أو نصوص قرآنية جديدة مضافة إلى المستودع.
