# تحقق تنظيف الألوان المباشرة في Design System — 2026-08-16

## النطاق

استُبدل الاستخدامان المباشران `text-white/60` و`text-white/70` في رأس صفحة مرجع نظام التصميم باستخدام `text-surface-dark-foreground/60` و`text-surface-dark-foreground/70`. لم تتغير قيم الألوان أو الشفافية أو تخطيط الصفحة؛ التغيير يحافظ على عقد Semantic Tokens ويمنع اعتماد الصفحة على اسم لون مباشر.

## الفحص البصري والتفاعلي

فُتحت `http://localhost:3004/design-system`، وظهر رأس الصفحة الداكن والنص الإنجليزي الصغير والوصف العربي بدرجات القراءة المتوقعة. بقيت كروت الإحصاءات، الأزرار، الشارات، الحقول، EmptyState وLoadingState متوافقة مع RTL والهوية الحالية. فُتحت نافذة Dialog التجريبية من زر «فتح Dialog»، ثم أُغلقت عبر مفتاح `Escape`، وعاد الـoverlay إلى حالته الأصلية.

## الفحص الإضافي

أعيد تشغيل بحث ساكن عن أنماط `bg-white` و`text-white` و`border-white` والألوان المباشرة الشائعة داخل `app` و`components` و`lib` و`server`، ولم يعثر على نتائج بعد التغيير. لا يعني ذلك أن قيم CSS hex داخل تعريفات التوكنز مخالفة؛ فهي مصدر التوكنز الدلالية الحالي.

لم تُجرَ أي عملية حفظ أو تعديل على بيانات المستخدم، ولم تظهر أخطاء runtime أو hydration أثناء التحقق. لم تُضف أسرار أو migrations.
