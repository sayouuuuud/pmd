# اختبار فلاتر المهام

التاريخ: 2026-08-16
المسار: `/tasks`

## التحقق البصري والتفاعلي

- ظهرت فلاتر الحالة الحالية: الكل، النهاردة، مفتوحة، مكتملة.
- ظهرت فلاتر إضافية RTL للأولوية والتصنيف مع أيقونة الفلترة.
- اختيار «أولوية عالية» عرض مهمتي «مراجعة تقرير الشغل الأسبوعي» و«تحضير عرض تقديمي للمشروع» فقط داخل عمود النهاردة، وأظهر الأعمدة الأخرى كفارغة.
- اختيار تصنيف «شغل» مع أولوية عالية قلّص النتيجة إلى «مراجعة تقرير الشغل الأسبوعي» فقط.
- ظهر زر «مسح الفلاتر» عند وجود فلتر إضافي، وأعاد كل المهام إلى توزيعها الأصلي بعد الضغط عليه.
- بقيت مؤشرات الأولوية، روابط المشروع والهدف، ونقل المهمة بين الأعمدة الزمنية ظاهرة ومتسقة مع التصميم الحالي.

## النتيجة

نجح اختبار فلاتر الأولوية والتصنيف، وعمل تقاطع الفلاتر ومسحها دون تعديل بيانات المهام أو كسر العرض RTL. لم يظهر خطأ runtime أثناء الاختبار.
