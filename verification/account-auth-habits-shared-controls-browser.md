# تحقق دفعة الحساب والمصادقة والعادات — 2026-08-17

## مساحة الحساب `/account`

- ظهرت الحقول المحلية مع `data-slot="input"` و`data-slot="textarea"`، بما في ذلك حقول الاسم والمدينة وبداية اليوم وفترة العمل والهدف الرئيسي.
- ظهرت أزرار حفظ التفضيلات والنسخ الاحتياطي والتصدير والاستعادة ومسح بيانات الجهاز وحذف الحساب مع `data-slot="button"`.
- زر تصدير بيانات الحساب بقي معطلًا كما هو متوقع عند غياب جلسة بعيدة، دون أخطاء تشغيل.
- فحص DOM أعاد عدادات صحيحة للمكونات المشتركة، واتجاه الصفحة RTL سليم.
- لم تُنفّذ أي عملية حفظ أو حذف أو رفع ملف أثناء التحقق.

## الحالة

الفحص المتصفحي للحساب ناجح مبدئيًا، وسيُستكمل باختبار `/habits` وتدفق المصادقة قبل تشغيل بوابات الجودة النهائية.

> ملاحظة: جميع التغييرات التجريبية يجب أن تبقى محلية ومؤقتة، ولا تُنفّذ عمليات حذف أو إرسال نهائية أثناء الاختبار.

نطاق الدفعة: ترحيل عناصر التحكم الخام في `account-workspace.tsx` و`auth-form.tsx` و`habits-workspace.tsx` إلى المكونات المشتركة دون تغيير handlers أو منطق التخزين.

حالة بوابات الجودة: TypeScript وESLint و`git diff --check` المبدئية نجحت؛ لم يُشغّل `next build` النهائي بعد.

حالة Git: لم تُنشأ دفعة لهذه المجموعة بعد.

## مساحة العادات `/habits`

- ظهرت بطاقات العادات وأزرار «عادة جديدة» والإكمال والأرشفة مع `data-slot="button"`.
- فُتح نموذج «أضف عادة تناسب يومك» بنجاح، وظهرت حقول الاسم والهدف مع `data-slot="input"`، والحقول المرتبطة مع `data-slot="select"`، وأزرار التكرار والحفظ والإغلاق المشتركة.
- اتجاه RTL والتخطيط العربي سليم، ولم تظهر أخطاء تشغيل في فتح النموذج.
- سيُختبر إدخال اسم مؤقت واختيار التكرار ثم إغلاق النموذج دون إرسال.

- أُدخل اسم «عادة اختبار مؤقت» في الحقل المشترك بنجاح، ثم اختُبر اختيار «أسبوعيًا» عبر Button المشترك دون إرسال النموذج.
- لم تُنشأ عادة جديدة ولم تُحفظ أي بيانات دائمة أثناء الاختبار؛ سيُغلق النموذج الآن عبر زر الإغلاق المشترك.

- أُغلق نموذج العادة بنجاح عبر زر الإغلاق المشترك، وعادت البطاقات الست إلى الواجهة دون ظهور «عادة اختبار مؤقت» أو أي تغيير محفوظ.

## المصادقة `/login`

- أظهر المسار `/auth` صفحة 404 لأن المسار غير موجود في التطبيق؛ جرى تصحيح مسار الاختبار إلى `/login` بناءً على بنية `app/login/page.tsx`.
- ظهرت صفحة تسجيل الدخول العربية باتجاه RTL، وظهر حقلا البريد وكلمة المرور كـ`data-slot="input"`، وزر الدخول وزر تبديل وضع المصادقة كـ`data-slot="button"`.
- لم تُدخل بيانات اعتماد ولم يُرسل نموذج المصادقة؛ سيُختبر زر تبديل الوضع فقط ثم يُعاد إلى الوضع الأصلي.

- نجح زر التبديل المشترك في تحويل النموذج إلى وضع «إنشاء الحساب»، وظهر حقل الاسم الإضافي كـ`data-slot="input"` مع بقاء البريد وكلمة المرور والزر الرئيسي ضمن النمط المشترك.
- لم تُدخل أي بيانات ولم يُرسل النموذج؛ ستُعاد الصفحة إلى وضع تسجيل الدخول قبل إنهاء الاختبار.

- أُعيد نموذج المصادقة إلى وضع تسجيل الدخول بنجاح، وبقيت الصفحة دون بيانات أو آثار اختبار، ولم تُنفذ أي عملية دخول أو إنشاء حساب.

## بوابات الجودة

نجحت `tsc --noEmit` و`eslint . --no-warn-ignored` و`git diff --check` و`next build` على الدفعة كاملة. ظهر فقط تحذير Next.js المعلوماتي بشأن تقادم convention الخاص بـmiddleware، ولم يمنع البناء أو يسبب أخطاء تشغيلية.
