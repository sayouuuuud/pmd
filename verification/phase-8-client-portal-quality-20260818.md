# محضر جودة المرحلة الثامنة — بوابة العميل والمشاركة والتعاون

**التاريخ:** 2026-08-18

**النطاق:** تنفيذ شريحة بوابة العميل والمشاركة الخارجية التجريبية فوق عقود الملكية الحالية، مع الحفاظ على فصل أدوار Workspace الداخلية عن أدوار العميل الخارجية.

## نتيجة الإغلاق

تم تنفيذ الشريحة المحلية التجريبية بنجاح، واجتازت البوابات البرمجية والتدقيقات النهائية. المشاركة الحالية **محلية داخل المتصفح** ولا تمثل بعد بوابة إنتاجية عامة أو نظام مصادقة للعملاء؛ وقد تم إبقاء هذا الحد صريحًا في الواجهة حتى لا يُفهم الرابط التجريبي على أنه حماية إنتاجية.

## المطابقة التفصيلية

| البند | التنفيذ | الحالة |
|---|---|---|
| اختيار عميل من Workspace | لوحة بوابة العميل تختار عميلًا من مساحة العمل الحالية | مكتمل |
| مشاركة مشروع محدد | لا يُنشأ الرابط إلا بعد اختيار مشروع مرتبط بالعميل | مكتمل |
| عرض الملخص والتقدم | البوابة تعرض الوصف، نسبة التقدم، الحالة، وشريط التقدم | مكتمل |
| عرض الخطوة التالية | تظهر `nextStep` عند مشاركتها ضمن المشروع | مكتمل |
| عرض المراحل | تعرض البوابة مراحل المشروع وحالة كل مرحلة | مكتمل |
| موافقة العميل على مرحلة | يسجل العميل تفاعل `milestone-approval` دون تغيير الحالة الداخلية تلقائيًا | مكتمل تجريبيًا |
| طلب تعديل | يرسل العميل تفاعل `change-request` مرتبطًا بالمشروع | مكتمل تجريبيًا |
| التعليقات | يرسل العميل تعليقات مرتبطة بالمشاركة والمشروع | مكتمل تجريبيًا |
| التحديثات الزمنية | تعرض البوابة تحديثات المشروع التي اختار المالك مشاركتها | مكتمل |
| روابط وملفات مسموح بها | يدعم المالك إضافة روابط عامة بعنوان ووصف إلى المشاركة | مكتمل محليًا |
| إظهار الدفعات اختياريًا | لا تظهر الدفعات إلا عند تفعيل `includePricing`، وتستبعد الدفعات الملغاة | مكتمل |
| إظهار الموعد اختياريًا | يتحكم `includeSchedule` في عرض الموعد | مكتمل |
| أدوار العميل | `client` للتعليق والمراجعة، `reader` للقراءة فقط، `reviewer` للمراجعة دون التعليق | مكتمل |
| إبطال الرابط | يستطيع مدير مساحة العمل إبطال المشاركة المحلية | مكتمل |
| انتهاء الرابط | يدعم الرابط تاريخ انتهاء، ويظهر كمنتهي عند تجاوزه | مكتمل |
| تفاعلات Workspace الداخلية | بقيت دعوات الأعضاء وأدوار المالك/المدير/العضو محكومة بـRoutes الحالية | محفوظ |
| حماية البيانات الداخلية | البوابة لا تعرض إلا `projectIds` و`includePricing` و`includeSchedule` و`resources` الموجودة في سجل المشاركة | مكتمل ضمن النطاق المحلي |

## الملفات الأساسية

تمت إضافة `lib/client-portal-contracts.ts` لعقود المشاركة والتفاعلات والتطبيع والتخزين المحلي وقدرات الأدوار. وتمت إضافة `components/workspace/client-portal-manager.tsx` لإدارة المشاركة من داخل Workspace، و`components/portal/client-portal-workspace.tsx` لعرض البوابة والتفاعلات، و`app/portal/[token]/page.tsx` لمسار الرابط الديناميكي. كما تم تركيب مدير البوابة داخل `components/workspace/workspace-workspace.tsx`.

## الحدود والقرار الأمني

لا توجد migration جديدة؛ مشاركة البوابة والتفاعلات محلية في `localStorage` لأن البيئة الحالية لا تحتوي اتصال قاعدة بيانات ولا جدولًا مخصصًا لمشاركة العميل. لا يتم إرسال بريد ولا إصدار جلسة عميل ولا تخزين كلمة مرور. لذلك لا يجوز اعتبار رابط `/portal/[token]` بديلًا عن نظام مصادقة إنتاجي قبل بناء طبقة مشاركة خادمية ذات ملكية `user_id` و`workspace_id`، وحفظًا آمنًا للرموز، وإبطالًا خادميًا، وسجل تدقيق.

> قرار الإغلاق: المرحلة الثامنة مكتملة ضمن النطاق التجريبي المحلي، مع تسجيل ترقية المصادقة الخادمية والمشاركة متعددة المستخدمين الإنتاجية كفجوة لاحقة صريحة وليست مخفية.
