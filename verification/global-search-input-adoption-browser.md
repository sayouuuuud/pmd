# تحقق اعتماد Input في البحث الشامل — 2026-08-16

## النطاق

اعتمد `GlobalSearchDialog` على `Input` المشترك لحقل البحث، مع تعطيل حدوده وخلفيته وring الافتراضي للحفاظ على شريط البحث الأصلي داخل `Dialog`.

## الفحص

فُتحت الصفحة الرئيسية ثم فُتح البحث الشامل. ظهر الحقل بالـplaceholder العربي «ابحث في مهامك وملاحظاتك ومشاريعك...» داخل Dialog مع زر الإغلاق وEsc، وبقيت الخلفية المعتمة وتخطيط RTL دون تغيير بصري ظاهر.

أُدخلت كلمة «مهمة» فظهرت نتيجتان داخل مجموعتي «المهام» و«خطة اليوم»، ثم أُغلق Dialog عبر Escape وعادت الصفحة الرئيسية دون تنقل أو بقاء استعلام.

**الحالة: PASS.**
