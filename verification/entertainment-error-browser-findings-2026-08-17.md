# نتائج اختبار المتصفح — live-region لخطأ نموذج الترفيه

**التاريخ:** 2026-08-17 UTC

## السيناريو

في `http://localhost:3004/entertainment` فُتح نموذج «إضافة فيلم أو مسلسل»، تُرك حقل الاسم فارغًا، ثم أُرسل النموذج دون إنشاء أي عنصر جديد.

## النتيجة المرئية

ظهرت الرسالة العربية:

> اكتب اسم الفيلم أو المسلسل أولًا.

## نتيجة فحص DOM

فحص DOM بعد الإرسال أعاد القيم التالية:

| الخاصية | القيمة |
|---|---|
| النص | `اكتب اسم الفيلم أو المسلسل أولًا.` |
| `role` | `alert` |
| `aria-live` | `assertive` |
| `aria-atomic` | `true` |
| عدد الحقول المرتبطة | `2` |
| `aria-invalid` للحقول المرتبطة | `true` |
| `aria-describedby` | `entertainment-item-error` |

الحقول المرتبطة هي حقل اسم العمل وحقل التصنيف، وهو سلوك متسق مع النموذج الحالي الذي يعرض خطأً واحدًا عند فشل التحقق الأساسي. لم تُنشأ بيانات جديدة ولم تتغير حالة العناصر الموجودة.

**الحكم:** PASS لاختبار المتصفح والدلالة الأساسية للرسالة.
