**النوع:** تحسين وصول ودلالة، دون تغيير في منطق البيانات أو واجهة API

## الفجوة الأصلية

كانت رسالتا التحقق في نموذجي إنشاء الملاحظة وتعديلها تستخدمان `role="alert"`، لكنهما لم تعلنا صراحةً خصائص `aria-live` و`aria-atomic`. هذا جعل عقد الإعلان أقل وضوحًا لبرامج قراءة الشاشة، خصوصًا عند تحديث النص داخل نفس العنصر. كما كان ينبغي التحقق من أن الحقل الفاشل يربط الرسالة عبر `aria-describedby` ويعلن حالة الفشل عبر `aria-invalid`.

## الإصلاح المنفذ

أضيفت إلى رسالتي الخطأ `#new-note-error` ورسالة خطأ تعديل الملاحظة الخصائص التالية:

| الخاصية | القيمة | الغرض |
|---|---|---|
| `role` | `alert` | تعريف الرسالة كخطأ مهم للمستخدم |
| `aria-live` | `assertive` | طلب إعلان الرسالة فور ظهورها |
| `aria-atomic` | `true` | إعلان محتوى الرسالة كاملًا عند تغيّره |

وحافظ الإصلاح على النصوص العربية، و`noValidate` في النموذجين، ومنطق التحقق الحالي، وربط الحقول عبر `aria-describedby`، وحالة `aria-invalid`، وlocalStorage fallback، دون تعديل عقد API أو قاعدة البيانات أو Better Auth.

## اختبار المتصفح

### إنشاء ملاحظة بعنوان فارغ

فُتحت صفحة `/notes`، وفُرغ عنوان نموذج الالتقاط السريع، ثم أُرسل النموذج. ظهرت الرسالة العربية الخاصة بعنوان الملاحظة الفارغ. أثبت فحص DOM أن عنصر الخطأ يحمل `role="alert"` و`aria-live="assertive"` و`aria-atomic="true"`، وأن حقل العنوان يحمل `aria-invalid="true"` و`aria-describedby` إلى معرّف الخطأ.

### تعديل ملاحظة بعنوان فارغ

فُتح نموذج تعديل أول ملاحظة، وفُرغ العنوان، ثم أُرسل النموذج. ظهرت الرسالة العربية `اكتب عنوان الملاحظة أولًا.`. أثبت فحص DOM القيم التالية:

| العنصر | القيمة |
|---|---|
| معرّف الخطأ | `note-note-1786967049031-edit-error` |
| نص الخطأ | `اكتب عنوان الملاحظة أولًا.` |
| `role` | `alert` |
| `aria-live` | `assertive` |
| `aria-atomic` | `true` |
| `aria-describedby` للحقل | `note-note-1786967049031-edit-error` |
| `aria-invalid` للحقل | `true` |

لم يُحفظ أي تعديل ولم تُنشأ بيانات اختبارية؛ اقتصرت الجولة على حالة التحقق الفاشلة. دليل فحص DOM محفوظ في `verification/notes-error-browser-findings-2026-08-17.md`، كما حُفظ ناتج console الخام في `/home/ubuntu/console_outputs/exec_result_2026-08-17_18-44-46_496.txt`.
