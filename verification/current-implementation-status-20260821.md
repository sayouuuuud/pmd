**تاريخ التحديث:** 21 أغسطس 2026

**الغرض:** توثيق ما تم تنفيذه فعليًا حتى الآن، وما يزال متبقيًا، مع الفصل الصريح بين التنفيذ المحلي/التجريبي والتنفيذ الإنتاجي.

## تعريف الحالات

- **مكتمل محليًا:** يعمل في الواجهة والمتجر المحلي أو بيانات Mock، واختُبر محليًا، لكنه لا يثبت جاهزية قاعدة البيانات أو تعدد المستخدمين.
- **مكتمل واجهيًا:** تجربة الاستخدام موجودة، لكن التخزين أو التكامل الحقيقي غير منفذ.
- **تجريبي:** نموذج صالح للاستعراض والاختبار، ولا يجوز وصفه كميزة إنتاجية.
- **جزئي:** نُفذ جزء من المتطلبات، وبقيت متطلبات أساسية.
- **غير منفذ إنتاجيًا:** لا يوجد ربط فعلي بالخدمة أو قاعدة البيانات المطلوبة.

# ثانيًا: ما يزال متبقيًا

## P1 — إغلاق قلب المنتج

### 1. المهام

**منفذ محليًا في دفعة 2026-08-21:**

- تبعيات المهام بين مهمة وأخرى مع منع الاعتماد على الذات والدورات والمراجع المحذوفة، وإظهار حالة الحظر.
- إجراءات جماعية موحدة للإكمال والنقل والأرشفة، مع تنظيف الخطة اليومية والتبعيات المرتبطة.
- Undo محلي محدود بعشر ثوانٍ للأرشفة والعمليات الجماعية.
- حفظ فلتر قائمة المهام وترتيبها محليًا.

**متبقي:**

- حذف جماعي نهائي مستقل عن الأرشفة.
- توحيد كامل واختبار آلي بين List وKanban وDashboard لكل تحديث.
- اختبار Drag and Drop إذا استمر ضمن النطاق النهائي.

### 2. الملاحظات

- محرر Rich Text أو Markdown مناسب للمحتوى الطويل إذا كان مطلوبًا نهائيًا.
- ربط مباشر كامل بالعميل والهدف، وليس المشروع والمهمة فقط.
- حفظ Draft غير مكتمل تلقائيًا واستعادته بعد إغلاق الصفحة.
- مزامنة سجل النسخ على الخادم بدل بقائه محليًا.
- فرز شامل حسب آخر تعديل والإنشاء والعنوان.

### 3. المشاريع والعملاء

- **منفذ محليًا:** تقدم مشروع محسوب تلقائيًا بقاعدة موحدة من المهام والـMilestones، ويُستخدم في لوحة المشاريع وتفاصيل المشروع وWorkspace Dashboard.
- مخاطر واعتماديات وTimeline للمشروع.
- ملفات ومرفقات فعلية للمشروع.
- **منفذ جزئيًا محليًا:** سجل نشاط المشروع يولّد أحداث تغير الحالة/التقدم والـMilestones وإكمال المهام المرتبطة؛ سجل العميل الكامل ما يزال متبقيًا.
- فلاتر وفرز متقدم للعملاء حسب الحالة والوسوم وآخر تعديل.
- توثيق وحماية بيانات الاتصال الحساسة على الخادم.

### 4. حالات النظام والتصميم

توحيد كل شاشة على الحالات التالية:

- Loading — موجود في عدد من الوحدات ولم يكتمل تعميمه.
- Empty — موجود في الوحدات الأساسية ولم يكتمل تدقيق كل المسارات.
- Server Error — متبقي كتجربة موحدة عبر كل الوحدات.
- Offline — **منفذ محليًا في مؤشر المزامنة العام** مع توضيح حفظ التغييرات محليًا.
- Local unsynced data — **منفذ في مؤشر المزامنة الحالي** للحالات pending/failed مع retry.
- Permission denied — متبقي للإغلاق مع الصلاحيات الإنتاجية.
- Expired link — مؤجل مع Client Portal الإنتاجي.
- Very long text/list — متبقي كتدقيق شامل.

كما يتبقى:

- مراجعة Keyboard Navigation شاملة.
- اختبار Zoom 200% والتباين و`prefers-reduced-motion`.
- توحيد المصطلحات العربية والتواريخ والعملات.
- استكمال مراجعة كثافة بعض الصفحات على الموبايل.

11. تفعيل CSP إنتاجية مناسبة بعد حصر كل مصادر الاتصال والسكربتات.
12. Backup/Restore ومراقبة وأخطاء إنتاجية لا تكشف تفاصيل قاعدة البيانات.

# رابعًا: الأولوية المقترحة من الآن

# الخلاصة الصريحة

المنتج الحالي **MVP محلي متقدم**: الواجهات الأساسية والمهام والملاحظات والمشاريع والعملاء والتقويم والعادات والبحث والأرشيف والمكتبة والفوترة التجريبية موجودة وقابلة للاستخدام والاختبار. لكنه **ليس منتجًا إنتاجيًا مكتملًا بعد** لأن المصادقة وقاعدة البيانات والتخزين والعزل متعدد المستخدمين وPortal والملفات والفوترة الخادمية وActivity الحقيقي لم تُغلق فعليًا.

لا ينبغي اعتبار أي جزء يعتمد على Mock أو Local Storage أو Metadata محلية تنفيذًا إنتاجيًا، حتى لو كانت واجهته مكتملة واجتازت اختبارات المتصفح المحلية.

# قائمة العمل المتبقي — بدون تنفيذ

> هذه القائمة هي النطاق المتبقي فقط. لم يتم تنفيذ البنود التالية في هذه الدفعة.

## أولوية عالية — قبل اعتبار الـMVP المحلي مغلقًا

### المهام

- حذف جماعي نهائي مستقل عن الأرشفة، مع تأكيد قوي وعدم حذف غير قابل للاسترجاع بالخطأ.
- توحيد تحديثات المهام بين List وKanban وDashboard.
- اختبار Drag and Drop إن ظل جزءًا من تجربة المهام النهائية.
- إضافة اختبار آلي لتبعيات المهام والإجراءات الجماعية عبر كل العروض، وليس اختبار المنطق فقط.

### الملاحظات

- إضافة محرر Rich Text أو Markdown إذا كان مطلوبًا للنسخة النهائية.
- ربط الملاحظة مباشرة بالعميل والهدف.
- حفظ Draft تلقائيًا واستعادته بعد إغلاق الصفحة أو تعطلها.
- نقل سجل النسخ من التخزين المحلي إلى الخادم.
- إضافة فرز شامل حسب العنوان والإنشاء وآخر تعديل.

### المشاريع والعملاء

- إضافة إدارة مخاطر واعتماديات وTimeline للمشروع.
- دعم ملفات ومرفقات فعلية للمشروع.
- استكمال سجل نشاط العميل، وليس أحداث المشروع فقط.
- إضافة فلاتر وفرز متقدم للعملاء حسب الحالة والوسوم وآخر تعديل.
- حماية بيانات الاتصال الحساسة وعرضها وفق صلاحية واضحة.

### حالات النظام والوصول

- تعميم Loading وEmpty وServer Error على جميع الوحدات والمسارات.
- إكمال Permission denied كتجربة موحدة.
- إكمال Expired link كحالة مستقلة في بوابة العميل.
- تدقيق النصوص والقوائم الطويلة.
- مراجعة Keyboard Navigation كاملة.
- اختبار Zoom 200% والتباين و`prefers-reduced-motion`.
- توحيد المصطلحات العربية والتواريخ والعملات.
- استكمال اختبار كثافة الصفحات على الهاتف.

## أولوية متوسطة — ميزات الإنتاج قبل الإطلاق

### Client Portal

- نقل روابط البوابة من التخزين المحلي إلى تخزين خادمي آمن.
- تفعيل جلسة/توثيق العميل بدل الاعتماد على token محلي فقط.
- تسجيل دخول البوابة وأحداث الوصول في Audit Log خادمي.
- إضافة Rate Limiting ومنع التخمين وإبطال الجلسات.
- ربط الصلاحيات فعليًا بالـWorkspace والعميل والمشروع على الخادم.
- دعم انتهاء الرابط وإبطاله وتجديده مع تحقق خادمي.
- مشاركة الملفات فعليًا داخل البوابة.
- اختبار نافذة خاصة ومستخدم عميل مستقل دون بيانات إدارة محلية.

### Library وStorage

- ربط Object Storage.
- رفع وتنزيل وحذف الملفات فعليًا.
- التحقق من الحجم وMIME type والامتداد.
- فرض ملكية الملف على المستخدم والـWorkspace.
- إنشاء روابط تنزيل مؤقتة.
- عرض تقدم الرفع وإعادة المحاولة والمعاينة.
- تطبيق سياسات المشاركة والصلاحيات.
- ترحيل Metadata المحلية إلى السجل الخادمي عند الحاجة.

### Billing وPDF

- تخزين العروض والفواتير على الخادم.
- إنشاء أرقام متسلسلة غير مكررة وآمنة.
- إعادة التحقق من السعر والكمية والإجمالي على الخادم.
- تطبيق قواعد التقريب والعملات والضرائب بدقة.
- إنشاء PDF فعلي قابل للتنزيل.
- إرسال العرض أو الفاتورة للعميل.
- تسجيل الدفع والتعديلات في Audit Log.
- منع تعديل الفاتورة النهائية دون سجل تغيير.
- إضافة Stripe فقط إذا أصبح الدفع الإلكتروني ضمن النطاق.

### Activity

- اتخاذ قرار نهائي: Agent Windows إنتاجي أو إبقاء الميزة تجريبية خارج النسخة الأولى.
- إن تم اعتمادها: بناء تطبيق/Agent Windows فعلي.
- إضافة موافقة واضحة وسياسة خصوصية.
- تشفير الإرسال ومنع التكرار.
- دعم تعدد الأجهزة.
- تفعيل الإيقاف المؤقت ووضع الخصوصية فعليًا.
- تطبيق سياسة احتفاظ وحذف خادمية.
