# تحقق دفعة دلالة أخطاء المصادقة العربية — 2026-08-17

## النطاق

راجعت هذه الدفعة أخطاء نموذج تسجيل الدخول وإنشاء الحساب في `components/auth/auth-form.tsx`. كان التحقق العربي موجودًا، وكانت أخطاء الحقول والخطأ العام تستخدم `role="alert"`، لكن خصائص `aria-live` و`aria-atomic` لم تكن صريحة في هذا المكوّن. الهدف هو جعل عقد الإعلان الدلالي واضحًا ومتسقًا مع بقية إصلاحات الوصول في المنصة، دون تغيير Better Auth أو التحقق أو الهوية البصرية.

## الإصلاح

أضيفت `aria-live="assertive"` و`aria-atomic="true"` إلى أخطاء الاسم والبريد الإلكتروني وكلمة المرور، وإلى رسالة الخطأ العامة. بقيت النصوص العربية، ومعرّفات `aria-describedby`، وحالات `aria-invalid`، ومنطق مسح الخطأ عند تعديل الحقل كما هي.

## اختبار المتصفح

فُتحت `http://localhost:3004/login`، ثم أُرسل النموذج فارغًا. ظهرت الرسالة العربية `اكتب البريد الإلكتروني أولًا.`، وبقي الحقل مرتبطًا بها عبر `aria-describedby="auth-email-error"` وحمل `aria-invalid="true"`. أظهر فحص DOM المباشر القيم التالية:

| الخاصية | النتيجة |
|---|---|
| النص | `اكتب البريد الإلكتروني أولًا.` |
| `role` | `alert` |
| `aria-live` | `assertive` |
| `aria-atomic` | `true` |
| `aria-describedby` للحقل | `auth-email-error` |
| `aria-invalid` للحقل | `true` |

لم تُستخدم بيانات اعتماد حقيقية، ولم يُرسل طلب مصادقة خارجيًا؛ الاختبار توقف عند التحقق المحلي للحقل الفارغ.
