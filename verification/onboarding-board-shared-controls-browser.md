# التحقق المتصفحي — onboarding والسبورة والمكونات المشتركة

**التاريخ:** 2026-08-17

## نطاق الدفعة

ترحيل عناصر التحكم في `components/onboarding/onboarding-flow.tsx` و`components/board/board-workspace.tsx` إلى `Button` و`Input` و`Select` المشتركة، مع الحفاظ على RTL، التصميم الحالي، ومنطق التنقل والإنشاء والتحويل كما هو.

## onboarding

- فُتحت الصفحة محليًا على `http://localhost:3004/onboarding`.
- ظهرت الخطوة الأولى بالعربية وباتجاه RTL، مع حقلي الاسم والمدينة كمكوّني `Input` مشتركين وزر «التالي» كمكوّن `Button` مشترك.
- تم الانتقال إلى خطوة إيقاع اليوم، وظهرت حقول بداية اليوم ووقت العمل باستخدام `Input` المشترك.
- تم الانتقال إلى خطوة الاتجاه، واختُبر اختيار «بناء عادات ثابتة» عبر `Button` مشترك دون إكمال الإعداد.
- ظهرت خطوة العادات والورد مع أربعة أزرار عادات كمكونات مشتركة وحقلي نوع الورد وهدفه كمكوّني `Select` مشتركين.
- فحص DOM في خطوة البداية: `2` Input مشتركان، `0` Select في الخطوة الأولى، `2` Button مشتركان، و`0` أزرار HTML خام داخل onboarding.
- فحص DOM في خطوة العادات والورد: `6` Buttons مشتركة، و`2` Select مشتركان، و`0` أزرار HTML خام.
- اتجاه الصفحة `rtl`، ولم تظهر أخطاء Console أثناء التنقل.
- لم يُضغط زر «ابدأ مساحتي»، ولذلك لم تُحفظ إعدادات onboarding أو أي بيانات تجريبية.

## السبورة

- فُتحت الصفحة محليًا على `http://localhost:3004/board`.
- ظهرت أداة اختيار السبورة، أزرار مناطق التجميع والألوان، وأزرار التحكم في التكبير باستخدام مكونات `Select` و`Button` المشتركة.
- فُتح نموذج Sticky Note دون إرسال، وظهرت حقول العنوان والملاحظة كـ`Input` مشتركين، وحقول المكان واللون والحجم والمجموعة كـ`Select` مشتركة، وزر «إضافة» كـ`Button` مشترك.
- فُحِصت بطاقات الملاحظات؛ أزرار النقل والتحويل والحفظ وحقلا المجموعة والحجم ظهرت من المكونات المشتركة.
- عُدّل عنوان Sticky Note مؤقتًا إلى «فكرة اختبار مؤقتة» ثم أُفرغ الحقل دون إرسال النموذج أو إنشاء ملاحظة.
- فحص DOM في السبورة: `9` Select مشتركة في الحالة الأساسية، و`32` Button مشتركة قبل فتح النموذج؛ وبعد فتح النموذج ظهرت `4` Inputs و`9` Select على الأقل ضمن نطاق السبورة بحسب عناصر الصفحة المرئية.
- الأزرار الخام الأربعة التي ظهرت في فحص الصفحة تخص شريط التخطيط العام (`إضافة سريعة`، البحث، التنبيهات، القائمة) وليست من ملف السبورة؛ لا توجد عناصر `<button>` خام في ملف `board-workspace.tsx` بعد الترحيل.
- اتجاه الصفحة `rtl`، ولم تظهر أخطاء Console.
- لم يُضغط زر «إضافة»، ولم تُنفذ تحويلات أو أرشفة أو تغييرات دائمة على بيانات السبورة.
