# اختبار تحرير عناصر خطة اليوم

- الصفحة: `/daily-plan`
- التاريخ: 2026-08-16
- السيناريو: فتح زر «تعديل العنصر» لعنصر «تحضير عرض تقديمي للمشروع»، تغيير العنوان مؤقتًا إلى «تحضير عرض تقديمي للمشروع — تعديل» والوقت من `10:00` إلى `10:30`، ثم الحفظ.
- النتيجة: انعكس العنوان والوقت فورًا في Timeline، وتغيّر اقتراح «تركيز الفترة الحالية» إلى العنوان المعدّل.
- الاستعادة: أُعيد العنوان إلى «تحضير عرض تقديمي للمشروع» والوقت إلى `10:00` وحُفظت القيم الأصلية.
- تحقق إضافي: أظهر سجل المتصفح اتصال HMR فقط وReact DevTools info، دون أخطاء JavaScript أو أخطاء مزامنة.
- تحقق الجودة: TypeScript وESLint و`git diff --check` و`next build` نجحت.

## ملاحظات النطاق

يُرسل التعديل البعيد عبر `PATCH /api/daily-plan/[id]` باستخدام `startAt` المقابل للوقت، بينما يستمر localStorage fallback عند عدم توفر قاعدة البيانات. تم أيضًا توحيد قبول حالة `skipped` في POST وPATCH لمسار خطة اليوم.
