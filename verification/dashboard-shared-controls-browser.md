# تحقق الصفحة الرئيسية — عناصر التحكم المشتركة

## النطاق

تم ترحيل عناصر `button` و`input` التفاعلية في `components/dashboard/dashboard-home.tsx` إلى `Button` و`Input` المشتركة، مع إبقاء روابط التنقل `Link` كما هي. شمل ذلك أزرار مهام اليوم، أزرار الصلوات، أزرار رفض/اعتماد/تعديل الاقتراحات، وزر التراجع، إضافة إلى حقل تعديل نص الاقتراح.

## التحقق المتصفحي — 2026-08-17

- فُتحت الصفحة الرئيسية على `http://localhost:3004/` وظهر المحتوى العربي باتجاه RTL دون أخطاء ظاهرة.
- ظهرت أزرار مهام اليوم وأزرار الصلوات وأزرار الاقتراحات داخل DOM كعناصر `button` مشتركة تحمل `data-slot="button"`.
- ظهرت عناصر التحكم المشتركة في TopNav والعناصر الإحصائية والبطاقات دون كسر التخطيط.
- اختُبر زر «اختبار مهمة يومية» بالنقر عليه؛ انتقلت الحالة محليًا من `2/7` إلى `3/7` ثم عادت بالنقر الثاني إلى `2/7`، ما يؤكد عمل handler دون إبقاء تغيير تجريبي.
- لم يُنفّذ اعتماد أو رفض أو حفظ تعديل دائم لأي اقتراح.
- لم تُضف migrations أو secrets، وبقي سلوك localStorage كما هو.

## بوابات الجودة

نجحت TypeScript وESLint و`git diff --check` و`next build` ضمن البوابات النهائية بعد تحديث سجلات التوثيق. ظهر تحذير Next.js المعلوماتي الخاص بتقادم convention الخاص بـmiddleware، وهو غير حاجز.
