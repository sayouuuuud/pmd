# نتائج اختبار المتصفح — live-region لخطأ نموذج العادات

**التاريخ:** 2026-08-17 UTC

في `http://localhost:3004/habits` فُتح نموذج «عادة جديدة»، تُرك حقل اسم العادة فارغًا، ثم أُرسل النموذج. ظهرت الرسالة العربية `اكتب اسم العادة أولًا.` دون إنشاء عادة جديدة.

| الفحص | النتيجة |
|---|---|
| النص | `اكتب اسم العادة أولًا.` |
| `role` | `alert` |
| `aria-live` | `assertive` |
| `aria-atomic` | `true` |
| الحقل المرتبط | حقل اسم العادة، `INPUT` |
| `aria-invalid` | `true` |
| `aria-describedby` | `habit-form-error` |

**الحكم:** PASS. الاختبار لم يغيّر البيانات المحلية أو ينشئ سجلًا جديدًا.
