# تقرير تحقق: إعلان إشعار PWA بالعربية

**التاريخ:** 2026-08-17

## النطاق
راجع التدقيق الساكن مكوّن `components/pwa/pwa-register.tsx`. كان إشعار تثبيت التطبيق أو توفر تحديث جديد يستخدم `role="status"` فقط، من دون `aria-live` و`aria-atomic` مكتملتين. هذا يجعل تحديث الإشعار أقل وضوحًا لقارئات الشاشة عندما يظهر بعد حدث المتصفح.

## الإصلاح
أضيفت `aria-live="polite"` و`aria-atomic="true"` إلى عنصر `aside` الذي يحمل `role="status"`. لم يتغير نص الإشعار العربي، ولا تصميمه، ولا أزرار «تثبيت» و«تحديث» و«إخفاء إشعار PWA»، ولا منطق تسجيل Service Worker أو fallback الشبكة/localStorage.

## الاختبار
شُغّل build إنتاجي وخادم Next على `http://localhost:3005/`. تحققت الصفحة من عنوان عربي، ومن سياق آمن، ومن وجود Service Worker controller فعّال. جرت محاولة محاكاة `beforeinstallprompt` صناعيًا، لكن Chromium لم يعرض الحالة الأصلية لإشعار التثبيت؛ لذلك لا يُسجل ذلك كاختبار إيجابي لظهور prompt الحقيقي. السبب لا يدل على خلل في خصائص live-region نفسها، بل على أن حدث التثبيت الصناعي لا يضمن سلوك المتصفح الأصلي أو قد يكون التثبيت الحالي يمنع prompt.

إثبات الإصلاح المتاح هو الفحص الساكن للكود، الذي يثبت وجود `role="status" aria-live="polite" aria-atomic="true"` على عنصر الإشعار. سُجلت حدود اختبار المتصفح صراحة في `verification/pwa-live-browser-test-2026-08-17.md` دون ادعاء نتيجة غير مثبتة.

## بوابات الجودة
نجحت TypeScript وESLint وNext build. نجح فحص ownership مع `45` route، و`41` route مرتبطة بالجلسة، و`41` route ذات ownership ظاهر، بلا مسارات ناقصة. نجح responsive audit في `34/34` حالة، وaccessibility audit في `34/34` حالة مع `0` إخفاقات. نجح `git diff --check` بعد تنظيف artifacts وإيقاف خادم الإنتاج المؤقت.

تحذير Next.js بشأن تقادم convention الخاص بـmiddleware معلوماتي فقط، ولم يمنع build أو التدقيق.

## حدود النطاق
لم تتغير عقود API أو قاعدة البيانات أو ملكية المستخدم أو أسرار المشروع، ولم تُنفذ `drizzle-kit generate`. لا يثبت هذا التحقق prompt حقيقيًا في كل متصفح؛ يثبت تعديل live-region وبوابات المشروع، مع توثيق الحاجة إلى اختبار يدوي على جهاز يدعم PWA prompt فعليًا إذا أريد إثبات السلوك الأصلي للمتصفح.

## القرار
الإصلاح البرمجي مكتمل وقابل للاعتماد، مع تصنيف اختبار prompt التفاعلي كدليل محدود لا كـPASS كامل لظهور الحالة الأصلية.
