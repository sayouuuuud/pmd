# اختبار وسوم الملاحظات المتعددة

- المسار: `http://localhost:3004/notes`.
- إنشاء ملاحظة اختبارية بعنوان «اختبار الوسوم المتعددة» ومحتوى عربي؛ تم اختيار الوسوم «شخصي» و«شغل» و«تطوير» معًا.
- بعد الحفظ ظهرت الملاحظة في الشبكة بعدّاد 4 ملاحظات، وظهرت الوسوم الثلاثة منفصلة داخل البطاقة بصيغة شرائح واضحة.
- فلتر «شغل» أخفى الملاحظات غير المطابقة وأبقى الملاحظة متعددة الوسوم؛ ظهر زر «مسح الفلتر» في RTL.
- البحث النصي «اختبار الوسوم» مع استمرار فلتر «شغل» أبقى الملاحظة نفسها، ما يثبت اجتماع البحث والفلترة.
- لا ظهرت أخطاء Runtime أو hydration في الصفحة أثناء التفاعل. بقيت تجربة localStorage fallback قابلة للاستخدام، بينما يظل الحفظ البعيد متوافقًا لأن الوسوم تُخزّن في حقل `tag` الحالي كسلسلة مفصولة بفواصل.
- بعد إعادة التحميل عادت جلسة التطوير إلى مجموعة البيانات البعيدة الحالية؛ لذلك يثبت الاختبار الحفظ المتفائل والفلترة داخل الجلسة، ولا يدّعي مزامنة بعيدة فعلية من دون بيانات backend اختبارية مخصصة.
- لم تُترك الملاحظة الاختبارية ضمن البيانات البعيدة الحالية بعد إعادة التحميل.
