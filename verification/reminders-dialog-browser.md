# تحقق نافذة التذكيرات — Dialog المشترك — 2026-08-16

## النطاق

استُبدل الغلاف المحلي لنافذة «تذكير جديد» في `components/reminders/reminders-workspace.tsx` بمكوّن `components/ui/dialog.tsx` المشترك. احتُفظ بكل الحقول الحالية: العنوان، النوع، الموعد، والتكرار، كما بقي نموذج الحفظ مرتبطًا بزر Dialog الخارجي عبر `form="new-reminder-form"`.

## الفحص البصري والتفاعلي

فُتحت صفحة `http://localhost:3004/reminders`، وظهرت قائمة التذكيرات والاقتراحات والعدادات بتخطيط RTL الحالي. بعد الضغط على «تذكير جديد» ظهرت النافذة بعنوان «تذكير جديد» ووصفها العربي، وظهرت الحقول الأربعة وقائمتا النوع والتكرار وزرا الإلغاء والحفظ. أُغلقت النافذة عبر `Escape`، وعاد الـoverlay إلى حالته الأصلية دون إنشاء تذكير أو تغيير عدادات الصفحة.

## السلامة

لم يتم إرسال النموذج أو حفظ عنصر تجريبي، ولم تتغير بيانات المستخدم. لم تُضف أسرار أو migrations. سلوك الإغلاق عبر زر X والإغلاق بالنقر خارج النافذة موفّر من Dialog المشترك، بينما يحتفظ مكوّن التذكيرات بمسح repeat label عند الإلغاء كما كان.
