# تحقق مساحة الديني — المكونات المشتركة

التاريخ: 2026-08-17

## النطاق

جرى ترحيل عناصر التحكم الخام في `components/religious/religious-workspace.tsx` إلى `Button` و`Select` المشتركتين، مع الحفاظ على التصميم العربي RTL والـhandlers والحالة المحلية. شمل ذلك زر تفعيل الصلاة، Select حالة كل صلاة، Select نوع الورد وهدفه، Select حالة حفظ كل سورة، وأزرار السنن والنوافل.

## فحص DOM

فُتحت `http://localhost:3004/religious` على الخادم المحلي. أكد الفحص أن اتجاه الصفحة `rtl`، وأن عناصر التحكم المرحّلة تحمل `data-slot` المشتركة: 55 Button و19 Select، إضافة إلى عناصر Input وTextarea الحالية. لم توجد أزرار خام أو Select خام داخل `main` (`rawButtons: 0`, `rawSelects: 0`). وظهرت خمسة عناصر Select لحالات الصلوات، مع خيارات «لم تُسجّل»، «في وقتها»، «جماعة»، «قضاء»، و«فائتة».

## الفحص البصري والتفاعلي

ظهر قسم صلوات اليوم والورد اليومي وخطة الحفظ والسنن والنوافل بصريًا ضمن الكروت الحالية دون تغيير في الهوية البصرية. ظهرت أزرار الصلوات والسنن وحقول الحالة والورد والحفظ بصورة تفاعلية سليمة. بدأ اختبار زر صلاة الظهر المرحّل إلى Button، وسيُعاد إلى حالته الأصلية بعد التحقق من التبديل، دون اعتماد تغيير دائم.

## بوابات الجودة الأولية

نجح فحص عدم وجود عناصر خام في الملف، ونجح TypeScript وESLint الخاص بالملف و`git diff --check`. لم تُشغّل بوابة `next build` النهائية قبل إكمال الفحص التفاعلي الكامل.


## التفاعل — الصلاة

اختُبر زر «صلاة الظهر» المرحّل إلى `Button`: تغيّرت الحالة مؤقتًا إلى «في وقتها» وارتفع المؤشر من 1/5 إلى 2/5، ثم أُعيد الضغط فعادت إلى «لم تُسجّل» وعاد المؤشر إلى 1/5. لم يبقَ تغيير تجريبي.

ظهرت أثناء الاختبار أزرار الصلوات وحقول Select الخاصة بها بصورة سليمة، كما بقيت بطاقة الورد وخطة الحفظ والسنن والنوافل ظاهرة دون أخطاء مرئية.


## التفاعل — Select الحفظ

اختُبر Select حالة حفظ سورة الفاتحة باختيار «تحتاج مراجعة» مؤقتًا؛ انعكس التغيير بصريًا في جدول المراجعة وأصبح الصف «مراجعة قريبة». أُعيد الاختيار إلى «بحفظها»، فعاد الصف إلى «جلسة حفظ جديدة» وبقيت قيمة الحفظ الأصلية. لم يُترك تغيير تجريبي.


## بوابات الجودة

نجحت بوابات الدفعة كاملة من جذر المشروع:

- `rm -f tsconfig.tsbuildinfo`
- `./node_modules/.bin/tsc --noEmit`
- `./node_modules/.bin/eslint . --no-warn-ignored`
- `git diff --check`
- `./node_modules/.bin/next build`

اكتمل إنتاج Next بنجاح مع توليد 25 صفحة. ظهر تحذير Next.js المعلوماتي المعتاد بشأن convention ملف `middleware`، ولم يمنع البناء.
