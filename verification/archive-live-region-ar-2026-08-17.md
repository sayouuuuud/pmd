# تحقق دفعة إعلان نتائج الأرشيف بالعربية

**التاريخ:** 2026-08-17

**النطاق:** `components/archive/archive-workspace.tsx`

## الفجوة

كان إشعار نتائج الاستعادة يُعرض بصريًا داخل عنصر يحمل `role="status"`، لكنه لم يحدد `aria-live` أو `aria-atomic`. لذلك لم تكن دلالة الإعلان الديناميكي مكتملة بما يكفي لقارئات الشاشة عند استعادة عنصر فردي أو مجموعة عناصر.

## الإصلاح

أضيفت الخاصيتان التاليتان إلى عنصر الإشعار الحالي دون تغيير النصوص أو التصميم أو منطق الاستعادة:

```tsx
<div role="status" aria-live="polite" aria-atomic="true">
```

وبذلك أصبحت رسائل النجاح مثل `تمت استعادة «يوم هادئ للتجربة» إلى اليوميات.` منطقة حية هادئة تعلن التغيير كوحدة واحدة. بقي fallback المحلي، واستعادة العملاء، والاستعادة الجماعية، ومدة اختفاء الإشعار كما هي.

## اختبار المتصفح

فُتحت صفحة `http://localhost:3004/archive`، ثم استُعيد عنصر اختبار غير حساس بعنوان `عميل تدقيق تجريبي`، وبعده عنصر `يوم هادئ للتجربة` لإعادة اختبار المسار. أظهر DOM الرسالة التالية بعد الاستعادة:

```json
{
  "text": "تمت استعادة «يوم هادئ للتجربة» إلى اليوميات.",
  "role": "status",
  "ariaLive": "polite",
  "ariaAtomic": "true"
}
```

بعد الاختبار أُعيدت تدوينة `يوم هادئ للتجربة` إلى الأرشيف. سجّل اختبار العميل استعادته محليًا وعاد عداد الأرشيف من 8 إلى 7، ثم أُعيدت التدوينة إلى الأرشيف بعد التحقق. لم تُستخدم بيانات حساسة أو حساب حقيقي.
