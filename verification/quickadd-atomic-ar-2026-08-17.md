# تقرير تحقق: تقوية إعلان خطأ Quick Add العربي

**التاريخ:** 2026-08-17
**المكوّن:** `components/layout/top-nav.tsx`
**نطاق الدفعة:** تحسين دلالة خطأ الإدخال في حوار «إضافة سريعة» دون تغيير parser أو التحقق أو منطق المعاينة والحفظ.

## الفجوة

كان عنصر خطأ Quick Add يستخدم `role="alert"` و`aria-live="assertive"`، لكنه لم يصرّح بـ`aria-atomic`. لذلك كانت المنطقة الحية تملك إعلانًا عاجلًا للنص العربي، من دون ضمان إعلان محتوى الرسالة كاملًا عند تغيّرها.

## الإصلاح

أضيفت الخاصية `aria-atomic="true"` إلى العنصر `#quick-add-error` مع إبقاء `role="alert"` و`aria-live="assertive"` و`aria-describedby` المرتبط بحقل الإدخال كما هي. لم يتغير نص الرسالة، أو parser، أو تدفق المعاينة، أو عمليات الحفظ المحلية.

## اختبار المتصفح

فُتحت الصفحة `http://localhost:3004/`، ثم فُتح حوار «إضافة سريعة» وأُرسل النموذج فارغًا. ظهرت الرسالة العربية:

> اكتب بيانات الإضافة أولًا بصيغة واضحة.

وأثبت فحص DOM الفوري القيم التالية:

| الخاصية | النتيجة |
|---|---|
| النص | `اكتب بيانات الإضافة أولًا بصيغة واضحة.` |
| `role` | `alert` |
| `aria-live` | `assertive` |
| `aria-atomic` | `true` |
| `aria-describedby` في الحقل | `quick-add-error` |

لم تُنشأ أي بيانات لأن الاختبار استخدم إدخالًا فارغًا، وبقيت حالة المنصة دون تغيير.
