## معيار المرحلة الأصلي

تتطلب المرحلة التجريبية تسجيل أو دعوة العميل، عرض المشاريع التي تمت مشاركتها معه فقط، عرض المراحل والتحديثات والملفات المسموح بها، إرسال تعليق أو طلب تعديل، تغيير حالة الموافقة على مرحلة أو ملف، ورؤية المواعيد والدفعات التي اختار المالك مشاركتها. كما تتطلب التعاون عبر دعوة عضو فريق أو عميل إلى Workspace، أدوارًا وصلاحيات أولية، تعيين المهام والمشاريع، تعليقات وMentions اختيارية، سجل تغييرات أساسي، وإزالة العضو وإبطال وصوله.

## ما هو موجود قبل تنفيذ المرحلة

| المجال | الحالة الحالية | الحد الموجود |
|---|---|---|
| Workspace داخلي | موجود تجريبيًا | أدوار `owner/admin/member`، أعضاء، دعوات يدوية، قبول وإبطال، وواجهة `/workspace` |
| العملاء | موجود | CRUD داخلي مقيد بعضوية Workspace مع localStorage fallback |
| ملف العميل | موجود | `/workspace/clients/[id]` يعرض المشاريع والمهام والدفعات والتحديثات للعضو الداخلي فقط |
| المشاريع | موجود | ارتباط عميل محليًا، خطوة تالية، مراحل، تسعير، دفعات وتحديثات |
| عقود الملكية المحلية | موجودة | `local-first-contracts.ts` يعرّف `personal/workspace/shared` وأدوارًا خارجية `client/reader/reviewer` وأدوار مشاركة `viewer/commenter/approver` وقدراتها |
| مشاركة خارجية | غير موصولة | لا يوجد سجل Share/Portal أو Route عام أو واجهة عميل أو تعليقات/موافقات مرتبطة بالمشاركة |
| قاعدة البيانات | مؤجلة | لا تُشغّل migrations أو `drizzle-kit generate`؛ المرحلة الحالية يجب أن تعمل محليًا أولًا وبحدود تجريبية واضحة |

## قرار التنفيذ للدفعة الحالية

تنفيذ Vertical Slice محلية قابلة للاختبار داخل الهوية الحالية، دون ادعاء جاهزية إنتاجية أو إرسال بريد أو مصادقة عميل حقيقية. ستستخدم عقودًا typed للمشاركة، وتخزينًا محليًا مع token تجريبي غير حساس، وصفحة بوابة تجريبية تعرض فقط الموارد التي يحددها المالك، مع تعليقات وطلبات تعديل وموافقة محلية، وتبقى المشاركة معزولة عن بيانات Workspace غير المصرح بها.

لن تُخزّن كلمات مرور أو أسرار عملاء، ولن تُنفذ مراقبة أو قراءة محتوى أو لقطات شاشة ضمن هذه الدفعة. سيظل اختبار قاعدة البيانات والجلسات الحقيقية، وإبطال token على الخادم، وإرسال البريد، واختبارات race/expiry، والتدقيق الأمني الإنتاجي حدودًا موثقة إلى مرحلة التقوية اللاحقة.

## الملفات المرشحة

`lib/local-first-contracts.ts` لإعادة استخدام الأدوار والقدرات، `lib/workspace-types.ts` لعقود العملاء، `components/workspace/workspace-workspace.tsx` لواجهة التحكم بالمالك، `components/workspace/client-profile-workspace.tsx` للعرض الداخلي، وملفات Route/page جديدة للبوابة التجريبية عند الحاجة. لا يوجد تعارض مع schema الحالي إذا بقيت الدفعة محلية ولم تُشغّل migrations.

## بوابات المرحلة

بعد التنفيذ يجب تشغيل TypeScript وESLint وWebpack build وroute ownership وresponsive وaccessibility، ثم اختبار المتصفح لمسار إنشاء المشاركة وعرض البوابة والتعليق/طلب التعديل/الموافقة وسحب المشاركة، مع التحقق من RTL وحالات التحميل والفراغ والخطأ والعمل دون backend.
