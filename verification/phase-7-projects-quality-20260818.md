# محضر جودة وإغلاق المرحلة السابعة — المشاريع والتحديثات والتسعير والمال

**التاريخ:** 2026-08-18

**النطاق:** استكمال توسعة المشاريع محليًا فوق بنية التحديثات والتسعير الموجودة، مع الحفاظ على RTL وCairo وSemantic Design Tokens وlocalStorage fallback.

## المطابقة التفصيلية مع معيار الإغلاق

| بند الخطة | التنفيذ | الدليل/الحالة |
|---|---|---|
| ربط المشروع بالعميل | أضيف `clientId?` إلى عقد المشروع المحلي، ويعرض نموذج الإنشاء قائمة العملاء، كما تعرض تفاصيل المشروع العميل المرتبط أو حالة عربية فارغة. | `components/projects/projects-workspace.tsx` و`lib/command-center-store.tsx`؛ PASS بصريًا |
| ملخص المشروع ونطاقه | بقي العنوان والوصف والهدف والموعد ضمن نموذج الإنشاء وتفاصيل المشروع، مع بطاقة النظرة العامة الحالية. | PASS؛ لا تغيير يكسر العقد السابق |
| الخطوة التالية | أضيف `nextStep?` إلى المشروع، وحقل إدخال عربي في نموذج الإنشاء، وبطاقة تفاصيل تعرض القيمة أو «لم تُحدد بعد». أزيلت الرسالة الثابتة من موضع بيانات المشروع لصالح القيمة المحلية. | PASS بصريًا |
| Milestones | أضيف `ProjectMilestone` بحالتي `pending/done`، مع تطبيع آمن عند hydration، وإضافة مرحلة من التفاصيل، وتعليمها مكتملة، وعدّاد مكتملة/إجمالي. | أضيفت مرحلة تجريبية ثم تحولت من `0/1` إلى `1/1` فورًا؛ PASS |
| أعضاء الفريق | بقيت ضمن عقود التعاون/Workspace الحالية، ولم تُخلط مع ملكية المشروع المحلية الجديدة. | خارج تعديل هذه الدفعة؛ لا regression |
| تحديثات زمنية مستقلة | كانت منفذة في الدفعة السابقة عبر `ProjectUpdate` وتبويب التحديثات وCRUD وremote sync. | PASS regression؛ ضمن نطاق المرحلة |
| السعر والعملة | كانت منفذة عبر `ProjectPricing` وحقول المبلغ والعملة والموعد والحالة. | PASS regression |
| دفعات متوقعة/مستحقة/مُحصلة/ملغاة | الحالات الأربع موجودة في واجهة التسعير، مع تحرير وتحصيل وإلغاء وربط مالي محلي/remote عند توفر credentials. | PASS regression |
| المدفوع والمتبقي | أضيف ملخص تبويب التسعير: الإجمالي، المحصل من `received`، والمتبقي من `expected/due`، مع تنسيق العملة. | ظهر `١٬٧٥٠ دولار` إجماليًا، `١٬٧٥٠ دولار` محصلًا، و`٠ دولار` متبقيًا؛ PASS |
| الربط بالمالية عند التحصيل | بقي مسار التحصيل السابق الذي ينشئ دخلًا محليًا idempotent ويستخدم Route محميًا عند توفر الجلسة وقاعدة البيانات. | PASS محليًا؛ اختبار قاعدة البيانات الإنتاجي مؤجل لغياب credentials |
| معيار شاشة واحدة | تعرض النظرة العامة العميل والخطوة التالية والمراحل والمهام، ويعرض تبويب التسعير الإجمالي والمدفوع والمتبقي وسجل الدفعات. | PASS بصريًا وتفاعليًا |

## حدود موثقة وليست فشلًا

الحقول `clientId` و`nextStep` و`milestones` محلية في localStorage عمدًا، لأن جدول `project` الحالي لا يحتوي هذه الأعمدة، ولا يجوز تشغيل `drizzle-kit generate` بسبب اختلاف journal المعروف. لم تُضف migration جديدة أو أسرار إلى المستودع. يبقى اختبار Neon/Better Auth الفعلي متعدد المستخدمين مشروطًا بتوفير `DATABASE_URL` و`BETTER_AUTH_SECRET` وبحل مشكلة journal بأمان.
