# تحقق مكونات الحقول والشارات المشتركة — 2026-08-16

## النطاق

أضيفت مكونات `Input` و`Textarea` و`Select` و`Badge` إلى `components/ui` باستخدام توكنات التصميم الدلالية، وحُدّثت صفحة `/design-system` لاستخدامها فعليًا في عرض الحقول والشارات.

## الفحص البصري والتفاعلي

فُتحت `http://localhost:3004/design-system` بصريًا، وظهرت الحقول والشارات داخل البطاقات المستديرة مع اتجاه RTL وخط Cairo. أُدخل النص العربي «نص تجريبي» في Input، وتغيّر Select إلى «هذا الأسبوع»، وظهر التركيز المرئي دون أخطاء. فُتح Dialog المرجعي ثم أُغلق عبر `Escape` للتأكد من استمرار سلوك المكوّن المشترك.

## السلامة

المكونات الجديدة تغلف عناصر HTML الأصلية وتحافظ على props القياسية، ويدعم كل مكوّن `className` للتخصيص المحدود عند الحاجة. لم تُضف بيانات أو API أو migrations أو secrets.

**الحالة: PASS.**
