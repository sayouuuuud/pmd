# تحقق StatCard المشترك

- التاريخ: 2026-08-16
- الصفحة: `http://localhost:3004/`
- النتيجة: نجح العرض البصري في RTL مع ظهور أربعة كروت إحصاءات: إنجاز المهام، خطة اليوم، العادات، وأعلى Streak.
- التحقق البصري: احتفظت الكروت بالزوايا المستديرة، خلفية `bg-card`، شارة التفاصيل ذات التوكن الدلالي، وحالة hover/focus المتوافقة مع التصميم الحالي.
- التحقق التفاعلي: النقر على كارت «إنجاز المهام» نقل إلى `/tasks` بنجاح.
- التحقق الرجعي: صفحة المهام فتحت دون أخطاء، وظهرت فلاتر الحالة والأولوية والتصنيف وبقية المحتوى.
- البيانات: لم تُعدّل أي مهمة أو عادة أو سجل مالي أثناء الاختبار.
