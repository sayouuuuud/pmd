# ملاحظات مصدر نص القرآن

**المصدر الرسمي:** [Al Quran Cloud API](https://alquran.cloud/api)

**مواصفات OpenAPI:** [OpenAPI YAML](https://api.alquran.cloud/v1/documentation/openapi/yaml)

## نتائج التحقق

- `GET https://api.alquran.cloud/v1/surah` يعيد قائمة السور كاملة وعددها 114، مع رقم السورة والاسم العربي والاسم الإنجليزي وعدد الآيات ونوع النزول.
- `GET https://api.alquran.cloud/v1/quran/quran-uthmani` يعيد الإصدار الكامل للقرآن في `data.surahs`، وكل سورة تحتوي `ayahs` مع `text` بالتشكيل و`numberInSurah` وبيانات الجزء والصفحة والحزب والركوع والسجدة.
- `GET https://api.alquran.cloud/v1/surah/{number}/quran-uthmani` موثق لجلب سورة واحدة بالإصدار العثماني.
- endpoint الحالي للمشروع يستخدم `ar.alafasy` لجلب نص السورة/الجزء مع الصوت/الإصدار الحالي، بينما دفعة الفهرسة ستستخدم مصدر النص `quran-uthmani` للقراءة، وتبقي التلاوة الحالية منفصلة.
- اختُبر endpoint الفهرس وendpoint النص الكامل بطلبات قراءة فقط في 2026-08-17، وكلاهما أعاد `code: 200` وبيانات عربية؛ ظهرت بداية الفاتحة بالتشكيل في endpoint النص الكامل.

## قرار النطاق

سنضيف فهرس السور الكامل إلى Route محلي مع cache قصير/مُعاد التحقق، ثم نستخدم أرقام السور الحقيقية بدل القائمة المختصرة الحالية. سيظل النص يُجلب عند اختيار السورة من المصدر الخارجي ولا يُخزّن في حالة المستخدم أو قاعدة بياناته. لا نكتب نصًا قرآنيًا يدويًا داخل المستودع.
