# تحقق ألوان تقويم الصلاة الدلالية

- التاريخ: 2026-08-17
- الصفحة: `http://localhost:3004/religious`
- التغيير: استبدال ألوان `amber-*` المباشرة في حالة اليوم الجزئي بتوكنز `partial` الدلالية (`bg-partial` و`border-partial-foreground/35`).

## النتائج

1. فتحت صفحة القسم الديني محليًا وظهرت بطاقة «ثبات الصلاة» وتقويم آخر 30 يومًا مع الحالات الثلاث دون أخطاء runtime أو hydration.
2. سجّلت صلاة الظهر مؤقتًا كـ«في وقتها» لإنشاء حالة جزئية لليوم، ثم فحصت خلايا التقويم عبر DOM وComputed Styles. ظهرت خلايا الأيام الجزئية بالصنف `bg-partial`، وباللون المحسوب `rgb(255, 243, 196)`، مع عنوان مثل `2026-08-15 · 2/5`.
3. أعدت صلاة الظهر إلى «لم تُسجّل» بعد الاختبار لتنظيف أثر التفاعل وعدم ترك تغيير تجريبي.
4. بقيت حالة اليوم المكتمل باللون الأساسي، وحالة اليوم غير المسجل بخلفية `muted`، مع الحفاظ على RTL والكروت الحالية.

## بوابات الجودة

- `tsc --noEmit`: ناجح.
- `eslint . --no-warn-ignored`: ناجح.
- `git diff --check`: ناجح.
- `next build`: ناجح، مع التحذير المعلوماتي المعتاد حول convention الخاص بـ middleware.

## ملاحظة

الاختبار استخدم بيانات localStorage الحالية في المتصفح، ولم يضف نصوصًا خارجية أو بيانات شخصية جديدة.

## الحالة

نجح الترحيل الدلالي للحالة الجزئية بصريًا وتفاعليًا، مع التوافق الرجعي للحالات الأخرى.
