# جامع نشاط Windows التجريبي

هذه المرحلة تضيف **بروتوكولًا تجريبيًا لا جامعًا خفيًا**. الملف `agent/windows-activity-agent.ps1` يعمل محليًا على Windows ويكتب جلسات التطبيق إلى `activity-outbox.ndjson` داخل `LOCALAPPDATA`.

## ما يجمعه الوكيل

يجمع الوكيل اسم العملية المرئية ووقت بداية ونهاية عينة النشاط ووقت الخمول التقريبي. يمكن تمرير قائمة عمليات مستثناة عبر `-ExcludedProcesses`، ويمكن تشغيل عينة واحدة عبر `-Once` أو تشغيل دوري بحد أدنى خمس ثوانٍ بين العينات.

## ما لا يجمعه

لا يقرأ الوكيل كلمات المرور أو ضغطات المفاتيح أو الحافظة أو محتوى الرسائل أو محتوى صفحات الويب، ولا ينشئ لقطات شاشة أو يسجل الصوت. عنوان النافذة لا يُحفظ افتراضيًا. أي مزامنة إلى المنصة اختيارية وتتم من واجهة النشاط بعد مراجعة المستخدم.

## التشغيل المحلي

```powershell
.\agent\windows-activity-agent.ps1 -Once
.\agent\windows-activity-agent.ps1 -IntervalSeconds 30 -ExcludedProcesses Teams,Spotify
```

يُفضّل فحص ملف outbox قبل أي مزامنة. الواجهة العربية في `/activity` تعرض البيانات المحلية وتسمح بتشغيل الجامع التجريبي أو إيقافه، تحديد عتبة الخمول، إدارة الاستثناءات، تصدير CSV، حذف جلسة واحدة أو السجل كاملًا، ومحاولة مزامنة الدفعات عند توفر جلسة مصادق عليها.

## المزامنة والانقطاع

تبقى الجلسات ذات الحالة `pending` في localStorage إذا لم يتوفر الخادم أو انتهت الجلسة. عند فشل المزامنة تتحول إلى `failed` مع رسالة محلية، ولا تُحذف تلقائيًا. SQL المرحلة `phase-13-windows-activity.sql` مؤجل عمدًا ولا يُشغّل في بيئة التطوير الحالية.

## حدود الإنتاج

هذا الوكيل ليس خدمة Windows نهائية ولا يثبت نفسه تلقائيًا ولا يعمل بصلاحيات مرتفعة. قبل الإنتاج يجب إضافة توقيع للحزمة، شاشة موافقة واضحة، سياسة احتفاظ، مصادقة مزامنة مخصصة، وتدقيق أمني مستقل.
